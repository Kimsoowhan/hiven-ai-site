## 1. 이 프로그램이 하는 일

Hi Coffer는 내 PC와 거기에 꽂는 저장 매체(USB 메모리, 외장 하드, 메모리 카드 등)에 흩어진 파일을 한곳에서 보고, 찾고, 정리하고, 중요한 파일을 암호로 잠가 보관하게 돕는 프로그램입니다. 다섯 가지 일을 합니다.

1. **목록표 만들기.** 연결된 저장 매체마다 어떤 파일이 있는지 적은 목록표를 만듭니다. 다시 만들면 앞 목록표와 견주어 추가·변경·이동·누락된 파일을 알려 줍니다. 이 일은 파일을 옮기지 않습니다.
2. **정리 제안.** 새 파일이 들어오는 폴더(입구 폴더)를 살펴서 어디에 두면 좋을지 제안합니다. 제안은 제안일 뿐이며, 사용자가 고르고 [선택 실행]을 눌러야 파일이 옮겨집니다.
3. **금고.** 고른 파일을 이 PC에서 암호화해 보관합니다. 원본은 제자리에 그대로 둡니다. 열쇠는 금고 비밀번호와 금고 복구 QR코드, 둘뿐입니다.
4. **찾기.** 모든 목록표에서 파일을 찾습니다. 지금 꽂혀 있지 않은 저장 매체의 파일도 마지막 목록표로 찾습니다.
5. **되돌리기.** 프로그램이 옮긴 파일은 작업 묶음 단위로 원래 자리로 되돌립니다.

프로그램이 지키는 약속은 홈 화면 맨 위 한 줄에도 적혀 있습니다.
- 영구 삭제 없음: 파일을 지우지 않고 격리함에 넣습니다. 언제든 다시 꺼낼 수 있습니다.
- 인증서·키는 옮기지 않음: 공동인증서·암호 키 파일은 자리를 바꾸지 않고 위치만 기록합니다.
- AI 제안은 승인 후 실행: 사용자가 확인하고 승인해야만 실행됩니다.
- 인터넷 통신 없음: 이 PC 안에서만 처리합니다. 파일과 목록이 밖으로 나가지 않습니다.
- 모든 변경 기록(변조 확인): 바뀐 적이 있으면 알아내는 방식으로 모든 변경을 적습니다.

이 판(베타1)은 한국어 화면만 있고, 모든 기능을 무료로 씁니다. 결제·구독 기능이 없고, 쓰는 환경은 Windows 10·11 PC·노트북입니다.

## 2. 설치와 처음 실행

### 2-1. 설치 전에 알아 둘 것

[안내 상자: 실행할 것]
- 새 판을 설치하기 전에 Hi Coffer를 닫으십시오. 켜져 있으면 설치 파일이 대신 닫을지 묻습니다. 데이터 폴더·설정·금고는 그대로 남습니다.
- 설치 파일은 두 번 눌러 그대로 실행하십시오.

[안내 상자: 실행하면 안 되는 것]
- 설치 파일이나 프로그램을 관리자 권한으로 실행하지 마십시오. 관리자 권한으로 실행하면 파일을 금고로 끌어다 놓는 일이 막힙니다.
- 설치 중에 컴퓨터를 끄거나 저장 매체를 빼지 마십시오.

### 2-2. 설치 순서

1. 받은 설치 파일(HiCoffer_Setup_0.1.27.exe)을 두 번 누릅니다.
2. 「Hi Coffer 설치」 첫 창에서 [다음]을 누릅니다. 이 창에는 처음 설치인지, 같은 판을 다시 설치하는지, 새 판으로 올리는지가 한 줄로 알려집니다. 어느 경우든 데이터 폴더·설정·금고는 그대로 둡니다.
3. 「설치 전 고지와 이용 조건을 읽어 주십시오.」 창에서 내용을 읽고 「위 내용을 읽고 확인했습니다」에 표시한 뒤 다음으로 갑니다.
4. 프로그램을 설치할 폴더를 확인합니다. 설명 글에 따라 데이터(목록표·원장·금고)의 자리는 여기서 정하지 않고 처음 실행할 때 따로 정합니다.
5. 「설치를 마쳤습니다」 창에서 「Hi Coffer 실행」을 고르고 마칩니다. 바탕화면과 시작 메뉴에 「Hi Coffer」 바로가기가 생깁니다.

설치 창은 관리자 권한 없이 현재 사용자 계정에만 설치합니다. 이 PC에 .NET Framework 4.8 이상이 필요합니다(Windows 10 2019년 5월 업데이트 이후와 Windows 11에는 기본으로 들어 있습니다). 없으면 설치 창이 알려 주므로 Windows 업데이트를 한 뒤 다시 설치하십시오.

[그림: 설치 첫 창]

### 2-3. 처음 실행: 「Hi Coffer 시작하기」 창

처음 실행하면 「Hi Coffer 시작하기」 창이 뜹니다. 제목은 「Hi Coffer에 오신 것을 환영합니다」입니다.

1. **사전 고지를 읽습니다.** 창 가운데의 글 상자가 사전 고지입니다(같은 글을 나중에 [정보] 화면의 [사전 고지 보기]로 다시 볼 수 있습니다). 열 가지 내용 가운데 중요한 것은 다음과 같습니다.
   - 모든 처리는 이 PC 안에서 이루어지고, 이 판에는 인터넷 통신 기능이 없습니다.
   - 영구 삭제는 하지 않습니다. 영구 삭제는 사용자가 탐색기에서 직접 합니다.
   - 공동인증서·개인키 파일은 옮기지 않고 위치만 기록합니다.
   - 금고 열쇠는 비밀번호와 금고 복구 QR코드뿐이며, 둘 다 잃어버리면 Hi Coffer 운영자도 열 수 없습니다.
   - 이 판에는 프로그램 안에서 스스로 판단하는 AI가 들어 있지 않습니다. AI 제안은 사용자가 파일을 직접 전달하고 가져올 때만 쓰이며, 확인·승인해야 실행됩니다.
   - 회원 가입이 없고 이름·연락처·결제 정보를 받지 않습니다. Hi Coffer ID는 이 기기에서 무작위로 만든 값이며 밖으로 보내지 않습니다.
2. **데이터 폴더를 정합니다.** 「데이터 폴더(목록표·원장·금고)」 칸에 기본값(사용자 폴더 아래 `HiCoffer`)이 들어 있습니다. 기본값을 그대로 쓰시기를 권합니다. 이 폴더에 목록표, 이벤트 원장, 금고 파일이 모입니다.
3. **금고 코드를 정합니다.** 「금고 코드(영문·숫자 4자, 자산 번호 앞부분: HC-코드-연도-일련-검증)」 칸에 영문·숫자 4자를 적습니다. 처음에는 `MZ01`이 들어 있습니다. 4자가 아니면 「금고 코드」 알림이 뜹니다.
4. **「위 내용을 읽고 확인했습니다」에 표시하면 [시작하기]가 눌립니다.** 표시하기 전에는 [시작하기]가 흐려서 눌리지 않습니다. [나가기]를 누르면 프로그램이 시작되지 않고 끝납니다.

[안내 상자: 실행하면 안 되는 것]
- 데이터 폴더를 OneDrive·Dropbox·Google Drive·iCloud Drive 같은 클라우드 동기화 폴더에 두지 마십시오. 목록표의 파일 이름·경로와 금고 파일이 클라우드로 올라갑니다. 그런 폴더를 고르고 [시작하기]를 누르면 「클라우드 동기화 폴더」 확인 창이 뜨고, [그래도 사용]과 [그만두기] 중에 고르게 됩니다.
- 데이터 폴더와 각 저장 매체 맨 위의 `00_관리` 폴더를 옮기거나 지우지 마십시오. 목록표·원장·금고가 들어 있습니다.

[그림: Hi Coffer 시작하기]

### 2-4. 데이터 폴더가 어디에 생기는가

| 자리 | 들어 있는 것 |
|---|---|
| 데이터 폴더 아래 `00_관리` | 시스템 구성 파일, PC 목록표, 이벤트 원장, 작업 묶음, 격리, AI 요청·제안, 작업 묶음 계획 |
| 각 저장 매체 맨 위 `00_관리` | 저장 매체 구성 파일, 저장 매체 목록표, 저장 매체 이벤트 기록, 격리 |
| 데이터 폴더 아래 `금고` | 암호화된 금고 파일과 금고 원장(암호화) |

저장 매체를 처음 관리할 때는 「처음 관리하는 저장 매체」 확인 창이 한 번 뜹니다. 사용자의 폴더와 파일은 그대로 두고 맨 위에 관리 기록 폴더(`00_관리`)만 만든다는 안내이며, [진행]과 [그만두기]가 있습니다.

### 2-5. 데이터 폴더를 찾지 못할 때

데이터 폴더를 USB 같은 저장 매체에 두었는데 빠져 있으면 「데이터 폴더를 찾을 수 없음」 창이 뜹니다. 그 저장 매체를 다시 꽂으면 인식되는 즉시 저절로 이어서 시작합니다. 폴더를 옮겼거나 이름을 바꿨다면 [데이터 폴더 다시 지정]을 누르고 기존 `00_관리` 폴더가 있는 폴더를 고르십시오. 목록표·원장·금고를 그대로 이어 씁니다. 빈 데이터 폴더를 저절로 새로 만들지는 않습니다. 시작하지 않고 나가려면 [나가기]를 누릅니다.

### 2-6. 프로그램을 켜고 끄는 법과 화면 구성

- 바탕화면이나 시작 메뉴의 「Hi Coffer」를 눌러 켭니다. 이미 켜져 있으면 새로 켜지 않고 열려 있는 창이 맨 앞으로 나옵니다.
- 창은 가로가 화면의 70%인 16:9 크기로 가운데에 열립니다(가장 작게 1080×608, 가장 크게 1344×756). 창을 키우면 목록이 늘어납니다.
- 창 맨 위 줄에는 제품 이름 「Hi Coffer AI Agent」, 판 「0.1.27 베타1」, 그리고 상태 표식이 있습니다.
- 상태 표식 세 가지는 눌러서 해당 화면으로 갈 수 있습니다.
  - 「금고 없음」·「금고 잠김」·「금고 열림」 → 금고 화면
  - 「감시 중」·「감시 꺼짐」 → 자동 정리 규칙 화면
  - 「자산 관리 상태」(불안·혼재·양호·최적) → 분류 체계(Hi DAM) 화면
- 왼쪽에 메뉴 열한 개, 오른쪽에 내용, 맨 아래에 상태 줄이 있습니다. 상태 줄에는 방금 한 일의 결과가 한 줄로 나옵니다.
- 작업이 돌고 있으면 내용 맨 위에 진행 띠가 나타나고, 상태 줄 왼쪽의 점이 도는 원으로 바뀝니다.
- 작업 중에 창을 닫으려 하면 「작업 중」 확인 창이 뜨고, [중지하고 닫기]와 [그만두기] 중에 고릅니다.
- 자판: F5는 새로 고침, Ctrl+F는 검색 화면으로 가기, Esc는 창 닫기(그만두기)입니다.
- 프로그램을 지우려면 Windows 설정의 앱에서 「Hi Coffer」를 제거하십시오. 프로그램만 지워지고 데이터 폴더, 각 저장 매체의 `00_관리`, 금고는 남습니다.

## 3. 화면 둘러보기

왼쪽 메뉴는 「자산」 묶음(홈, 장치·매체, 자산 탐색, 분류 체계(Hi DAM), 제안함, 자동 정리 규칙, 금고, 검색), 「기록」 묶음(이력·되돌리기, 격리함), 그리고 구분선 아래 「정보」, 모두 열한 개입니다. 아래 열한 화면을 메뉴 순서대로 설명합니다.

모든 화면에서 단추 줄은 같은 규칙입니다. 맨 앞의 가장 눈에 띄는 단추가 그 화면의 주 단추이고 Enter를 눌러도 실행됩니다. 단추가 많은 화면에는 맨 끝에 [더 보기 ▾]가 있어 눌러서 나머지 단추를 고릅니다. 표의 줄은 한 번 누르면 고르고, 오른쪽 단추를 누르면 그 줄에 쓸 수 있는 메뉴가 나옵니다. 표 머리를 누르면 그 칸 순서로 정렬됩니다.

### 3-1. 홈

[그림: 홈]

**무엇을 보는 화면입니까.** 연결된 저장 매체와 제안·금고 현황을 한눈에 봅니다. 프로그램을 켜면 처음 보이는 화면입니다.

**화면 구성**
- 카드 네 장: 「연결 매체」(연결된 개수), 「제안 대기」(대기 중인 제안 건수), 「금고」(없음·잠김·건수), 「자산 관리 상태」(불안·혼재·양호·최적). 카드를 누르면 각각 장치·매체, 제안함, 금고, 분류 체계(Hi DAM) 화면으로 갑니다.
- 약속 칸: 1장의 다섯 가지 약속. 올려 놓으면 풀이 글이 뜹니다.
- 「다음 할 일:」 한 줄: 지금 상황에 맞는 다음 일을 알려 줍니다(연결된 저장 매체가 없으면 연결하라는 글, 목록표가 없으면 목록표를 갱신하라는 글, 대기 중인 제안이 있으면 제안함에서 확인하라는 글).
- 「최근 활동」 표: 시각 · 유형 · 실행한 쪽 · 결과 · 내용. 줄을 두 번 누르면 이력·되돌리기 화면으로 가고, 오른쪽 단추 메뉴의 「이력에서 보기」도 같습니다.

AI 산출물 → 사업 폴더 · 메신저 받은 파일 → 97.04 · 카메라 사진·영상 → 97.01 · 화면 캡처·스캔 → 98 · 웹 다운로드 → 97.05 · 신분·학위·자격 서류 → 01 · 세무·법무 서류 → 07 · 강의·과정 자료 → 05 · 같은 내용 사본 → 격리 제안 · 98 기간 경과 알림 · 보호 자산(인증서·키) · 이상징후 → 즉시 격리.

**설정 상자:** 「감시 주기(분)」(1~120분, 처음 값 5분) · 「자동 실행」 확인란(「감시 중 A1 규칙(규칙 자동)과 고정 규칙은 자동 실행」) · 「고른 규칙의 실행 수준」 고르기와 [수준 적용] · 「입구 폴더」 목록.

### 3-7. 금고

[그림: 금고]

**화면 구성:** 금고 상태 상자(왼쪽에 「잠김」 또는 「열림」 표식과 한두 줄 글) 아래에 금고 표. 표 칸은 번호 · 이름 · 크기 · 원본 지문(SHA-256) · 넣은 때 · 상태 · 원래 위치입니다. 상태 상자에 올려 놓으면 「원본 확인」(넣을 때 기록한 원본 지문과 같은지 확인), 「법적 효력」(법적 원본 증명이 아님), 「인증서·키」(넣지 않고 위치만 기록)가 풍선으로 나옵니다. 파일을 표로 끌어다 놓으면 금고에 넣을 수 있습니다(금고가 열려 있을 때만).

### 3-8. 검색

[그림: 검색]

**무엇을 보는 화면입니까.** 모든 목록표에서 파일을 찾습니다. 분리된 저장 매체도 마지막 목록표로 찾고, 연결된 저장 매체의 결과는 폴더를 바로 열 수 있습니다. 아무것도 바꾸지 않습니다.

**화면 구성:** 맨 위 찾기 줄에 입력 칸(오른쪽 ✕로 지움), 고르기 세 개(저장 매체 · 영역 · 등급), [검색] 단추가 있습니다. 입력 칸 아래 글: 「이름·경로 일부나 자산 번호로 찾습니다(낱말이 여럿이면 모두 들어 있는 항목을 찾습니다).」 결과 표 칸은 저장 매체 · 연결 · 분류 · 등급 · 크기 · 수정 시각 · 자산 번호 · 경로입니다. 등급 고르기는 전체, D0, D1, D2, D3, D4입니다.

**단추**

## 4. 자주 하는 일 차례

### 4-1. 장치를 연결해 목록표 만들기

1. 정리하려는 USB 메모리나 외장 하드를 PC에 꽂습니다.
2. 왼쪽 메뉴에서 「장치·매체」를 누릅니다. 목록에 저장 매체가 「인식」으로 나타나면 읽힌 것입니다.
3. 목록에서 그 저장 매체의 줄을 한 번 눌러 고릅니다.
4. [목록표 만들기·대사]를 누릅니다.
5. 처음이면 「처음 관리하는 저장 매체」 창이 뜹니다. 사용자의 폴더와 파일은 그대로 두고 맨 위에 `00_관리`만 만든다는 안내를 읽고 [진행]을 누릅니다.
6. 진행 띠가 도는 동안 기다립니다. 멈추려면 [중지]를 누릅니다.
7. 「목록표 만들기·대사 결과」 창이 뜨면 읽고 [닫기]를 누릅니다. 상태 줄에 「목록표 완료」가 나옵니다.

저장 매체가 「불가」로 나오면 7장이 아니라 5-5의 「저장 매체를 읽을 수 없습니다」 창 안내를 먼저 따르십시오.

### 4-2. 제안 받아 정리하기

1. 「제안함」 화면에서 [입구 폴더 검사]를 누릅니다. 입구 폴더(다운로드 등)가 없으면 먼저 「자동 정리 규칙」의 [입구 폴더 추가]로 정합니다.
2. 표에 제안이 올라옵니다. 줄에 마우스를 올려 「지금 위치」, 「실행 후 위치」, 「이유」를 읽습니다.
3. 옮겨도 좋은 줄만 확인 칸에 표시합니다. 한꺼번에는 [모두 선택]을 쓰고, 지우려면 [선택 해제]를 누릅니다. 실행할 수 없는 줄(흐린 글씨)은 고를 수 없습니다.
4. [선택 실행]을 누릅니다.
5. 「실행 확인」 창이 몇 건을 어떻게 옮기는지 알려 줍니다. 맞으면 [실행], 아니면 [그만두기]를 누릅니다.
6. 「실행 결과」 창에서 결과를 읽고 [닫기]를 누릅니다.
7. 잘못 옮겼다면 4-5로 되돌립니다.

분류 체계(Hi DAM)에 맞춰 저장 매체 전체를 정리하려면 「분류 체계(Hi DAM)」 화면에서 [분류 체계(Hi DAM) 적용] → [영역 폴더 만들기] → [정리 계획 만들기] 순서로 하고, 쌓인 제안을 위와 같이 [선택 실행]으로 마칩니다.

### 4-3. 금고에 넣고 잠그기

**금고 만들기(처음 한 번)**
1. 「금고」 화면에서 [금고 만들기]를 누릅니다.
2. 「금고 만들기」 창에서 비밀번호를 두 번 입력하고 [금고 만들기]를 누릅니다. 비밀번호는 화면에도 파일에도 저장되지 않으므로 외워 두거나 안전한 곳에 적어 두십시오. 영문·숫자·기호를 섞어 길게 정하는 것을 권합니다.
3. 몇 초 걸립니다(열쇠 계산). 이어서 「금고 복구 QR코드 만들기 · 기기마다 1개」 창이 뜹니다.
4. 창 안내를 읽고 [금고 복구 QR코드파일 저장위치 설정]을 누릅니다. 파일 이름은 `HiCoffer_금고복구QR_…png` 꼴로 제안되며, USB 같은 외부 저장 매체를 골라 저장합니다. Windows가 설치된 드라이브를 고르면 「외부 저장 매체에 저장」 확인 창이 한 번 더 묻습니다.
5. 「저장했습니다」 알림 뒤 「금고 복구 QR코드파일을 안전한 곳에 저장했습니다」에 표시하면 [저장 완료]가 눌립니다. 누르면 금고가 완성됩니다.

**파일 넣기**
1. 금고가 잠겨 있으면 [금고 잠금 및 해제]를 눌러 비밀번호를 넣고 엽니다(상태 상자가 「열림」으로 바뀝니다).
2. 넣는 길은 세 가지입니다. ① 탐색기에서 파일을 금고 표로 끌어다 놓습니다. ② [금고 후보 보기(R0 문서)]에서 고릅니다. ③ 검색·자산 탐색 화면에서 파일을 골라 [금고에 넣기]를 누릅니다.
3. 「금고에 넣기」 확인 창에서 개수와 파일 이름을 확인하고 [넣기]를 누릅니다.
4. 넣은 파일은 금고 표에 번호와 함께 나타납니다. 원본은 제자리에 그대로 있습니다.
5. 제대로 들어갔는지는 [원본 확인(선택)] 또는 [모두 확인]으로 봅니다.

**잠그기**
1. 일을 마치면 [더 보기 ▾] → 「금고 잠금 및 해제」를 누릅니다. 「금고를 잠갔습니다」가 나오고 맨 위 표식이 「금고 잠김」으로 바뀝니다.

[안내 상자: 실행하면 안 되는 것]
- 인증서·개인키 파일은 금고에 넣을 수 없습니다.
- 금고 복구 QR코드파일을 PC 안에만 두지 마십시오. PC를 초기화하면 함께 사라집니다.

### 4-4. 찾기

1. 「검색」 화면(Ctrl+F로도 갑니다)에서 입력 칸에 찾을 말을 적습니다. 파일 이름의 일부, 경로의 일부, 자산 번호가 됩니다. 낱말을 여럿 적으면 모두 들어 있는 것만 찾습니다.
2. 필요하면 「저장 매체」·「영역」·「등급」 고르기로 범위를 좁힙니다.
3. [검색]을 누르거나 Enter를 누릅니다.
4. 결과 줄을 두 번 누르면 그 파일이 있는 폴더가 열립니다. 지금 꽂혀 있지 않은 저장 매체의 결과는 폴더를 열 수 없으므로 저장 매체를 꽂은 뒤 다시 누릅니다.

### 4-5. 되돌리기

**방금 정리한 것을 되돌릴 때**
1. 「이력·되돌리기」 화면을 엽니다.
2. 위 표에서 되돌릴 작업 묶음을 한 번 눌러 고릅니다. 아래 표에 그 묶음의 내용이 나옵니다.
3. [선택 묶음 되돌리기]를 누릅니다.
4. 「되돌리기」 확인 창을 읽고 [되돌리기]를 누릅니다.
5. 「되돌리기 결과」 창에서 결과를 확인합니다.

**Hi Coffer가 옮긴 모든 것을 처음 구조로 되돌릴 때:** [원래 구조로 되돌리기]를 쓰고 「원래 구조로 되돌리기」 확인 창을 읽은 뒤 [되돌리기]를 누릅니다.

### 4-6. 격리함에서 꺼내기

1. 「격리함」 화면을 엽니다.
2. 표에서 꺼낼 항목을 고릅니다(여러 줄도 됩니다).
3. [원래 위치로 복원]을 누릅니다.
4. 「복원」 확인 창에서 [복원]을 누릅니다. 같은 이름이 있으면 「이름 (2)」로 복원됩니다.
5. 「복원 결과」 창에서 결과를 확인합니다.

모든 창은 Esc로 닫을 수 있고, 닫으면 [그만두기]와 같습니다(아무것도 실행하지 않음). 창 너비는 440·560·720 세 가지입니다. 머리 아래의 색 줄 하나가 창의 성격을 알려 줍니다(5-2).

### 5-2. 팝업(알림 창과 확인 창)

팝업은 두 가지로 나뉩니다.
- **알림 창:** 결과나 안내를 알립니다. 단추는 [닫기] 하나입니다.
- **확인 창:** 실행하기 전에 무엇이 어디서 어디로 몇 건인지 알리고 묻습니다. 단추는 [하는 일](예: [실행], [되돌리기], [복원], [넣기], [해지])과 [그만두기]이고, **Enter를 누르면 [그만두기]가 눌립니다.** 곧 아무것도 하지 않는 쪽이 안전한 기본입니다.

**색 줄의 뜻(창 머리 아래의 가는 줄)**

| 색 줄 | 갈래 | 뜻 | 예 |
|---|---|---|---|
| 파란 줄 | 알림 | 결과를 알리거나 안내함. 급히 할 일은 없음 | 「실행 결과」, 「금고에 넣기」 확인, 「복원 결과」, 「이미 적용함」, 「정리 계획」 |
| 주황 줄 | 경고 | 선택이 필요하거나 일이 막혔으니 읽고 판단해야 함. 확인 창의 [하는 일] 단추가 붉은 계열로 바뀜 | 「선택 없음」, 「저장 매체 분리됨」, 「금고 잠김」, 「작업 중」, 「되돌리기」 확인, 「금고 해지」 확인 |
| 빨간 줄 | 위험 | 실패했거나 데이터·열쇠에 문제가 생김 | 「잠금 해제 실패」, 「복구 실패」, 「이벤트 원장 확인 필요」, 「저장하지 못했습니다」, 처리하지 못했을 때의 오류 창 |

**일이 실패했을 때의 창(빨간 줄):** 제목에 작업 이름이 나오고 본문은 「처리하지 못했습니다.」, 「원인:」, 「남은 상태:」(이미 끝난 항목은 이력에 기록되어 있고 끝나지 않은 항목은 바뀌지 않았다는 안내), 「복구:」(이력·되돌리기 화면에서 그 묶음을 되돌릴 수 있다는 안내), 오류 기록 자리 순서로 나옵니다. 금고·열람·검색·원본 확인은 「금고와 원본 파일은 바뀌지 않았습니다.」로 대신합니다. 「원인」 줄에는 Windows가 준 글이 그대로 나올 수 있습니다. 그 글과 오류가 난 때를 적어 두었다가 7장대로 문의하십시오.

**[그만두기]의 뜻:** 확인 창이나 입력 창을 닫고 아무 일도 하지 않습니다. 이미 실행한 일에는 영향이 없습니다. Esc와 같습니다. 단, 이미 도는 작업을 멈추는 단추는 [그만두기]가 아니라 [중지]입니다.

**[중지]의 뜻:** 돌고 있는 작업을 멈추라는 요청입니다. 상태 줄에 「중지 요청: 지금 처리 중인 항목까지 마치고 멈춥니다」가 나옵니다. 지금 처리 중인 항목은 끝까지 마치고 멈추며, 그때까지 끝난 항목은 이력에 기록되고 나머지는 바뀌지 않습니다. 멈춘 뒤에는 상태 줄에 「중지했습니다(끝난 항목은 이력에 기록)」가 나옵니다.

**진행 띠와 진행 창:** 작업이 오래 걸리면 내용 맨 위에 진행 띠가 나타납니다(작업 이름 · 지금 단계 · [자세히] · [중지]). 아주 빨리 끝나는 일은 상태 줄에만 나옵니다. [자세히]를 누르면 「진행」 창이 열리고 「과정 기록」(시각 · 한 일)과 상태 표식(「진행 중」·「완료」·「일부 완료」·「멈춤」)이 보입니다. [창 닫고 계속]은 창만 닫고 작업은 계속하며, 작업이 끝나면 [닫기]가 나옵니다. 작업 중에 다른 화면으로 가도 작업은 계속됩니다. 다른 작업을 또 시작하면 「작업 중」 알림이 뜨며 시작되지 않으므로 끝난 뒤에 다시 하십시오.

### 5-3. 자주 만나는 알림

| 제목 | 뜻과 할 일 |
|---|---|
| 저장 매체 선택 / 선택 없음 | 목록에서 줄을 먼저 고르십시오. |
| 저장 매체 분리됨 / 매체 분리됨 | 그 저장 매체가 지금 꽂혀 있지 않습니다. 꽂은 뒤에 다시 하십시오. 목록표 검색은 마지막 목록표로 됩니다. |
| 금고 잠김 | 금고를 먼저 여십시오. |
| 처음 관리하는 저장 매체 | 맨 위에 `00_관리`만 만든다는 안내입니다. 읽고 [진행]을 누릅니다. |
| 보호 자산 제외 | 인증서·개인키는 금고에 넣지 않고 위치만 기록합니다. |
| 관리자 권한 실행 | 관리자 권한으로 켜지면 금고로 파일을 끌어다 놓을 수 없습니다. 창을 닫고 바탕화면이나 시작 메뉴의 「Hi Coffer」를 눌러 다시 켜십시오. |
| Hi Coffer가 응답하지 않습니다 | 이미 켜진 Hi Coffer가 응답하지 않을 때 뜹니다. [닫고 새로 시작]을 누르면 응답하지 않는 것을 닫고 다시 시작합니다. 진행 중이던 정리 작업은 이력·되돌리기에서 확인하고 복구합니다. |

### 5-4. 안내 창에 나오는 「실행할 것」과 「실행하면 안 되는 것」

저장 매체 안내 창(5-5)에는 파란 상자 「실행할 것」과 빨간 상자 「실행하면 안 되는 것」이 나란히 나옵니다. 파란 상자는 해야 할 일, 빨간 상자는 하면 피해가 커지는 일입니다. 이 설명서의 상자도 같은 이름을 씁니다.

### 5-5. 저장 매체를 읽을 수 없을 때: 두 안내 창

**「저장 매체를 읽을 수 없습니다」 창.** 저장 매체가 꽂혀 있는데 읽히지 않으면(손상·USB 장치 인식 실패·응답 없음) 뜹니다. 장치·매체 화면 「연결」 칸에는 「불가」로 표시됩니다. 이 창은 Windows의 「포맷하시겠습니까?」 창보다 먼저 보이도록 닫을 때까지 맨 위에 있습니다. 세 단계로 안내합니다.

1. **1단계.** [안내 상자: 실행할 것] 저장 매체를 USB 포트에서 뺐다가 잠시 후(10초쯤) 다시 꽂아 보십시오. 다시 꽂으면 창에서 바로 확인합니다.
2. **2단계 「USB 포트·연결선을 확인해 주십시오」.** 다른 USB 포트에 PC로 직접(허브·연장선 없이) 꽂아 보고, 연결선이 따로 있으면 다른 연결선으로도 꽂아 봅니다. 같은 USB 포트에 다른 저장 매체를 꽂아 읽히면 그 USB 포트는 정상입니다. 해 본 것은 ■로 표시됩니다. 다 해 보고도 읽히지 않으면 [모두 해 봤지만 읽히지 않습니다](깜빡이는 경고 단추)를 누르십시오. 다시 꽂아도 읽히지 않는 일이 5번 되풀이되면 저절로 3단계로 바뀝니다.
3. **3단계 「저장 매체 문제」.** 「이 저장 매체에는 문제가 있습니다. 이 저장 매체는 제조사에 수리를 요청해 주십시오.」

[안내 상자: 실행하면 안 되는 것]
- Windows가 이 저장 매체를 「포맷」하거나 「초기화」하라고 물으면 [취소]를 누르십시오. 포맷하거나 초기화하면 저장 매체 안의 자료가 모두 지워집니다.
- 연결이 안정될 때까지 이 저장 매체로 파일을 옮기거나 복사하지 마십시오.
- 3단계에서 저장 매체를 더 이상 빼고 꽂기를 되풀이하지 마십시오(손상이 커질 수 있습니다).

연결이 끊겼다 이어졌다 하면(60초 안에 여러 번) 「연결이 불안정합니다」 안내가 나옵니다. USB 포트나 연결선 접촉 문제일 수 있으므로 다른 USB 포트나 다른 연결선으로 연결하십시오.

이 창은 상황이 풀리면 저절로 닫힙니다. 정상으로 읽히면 20초 뒤, 저장 매체를 뺀 것이 확인되면 20초 뒤, 3단계에서는 30초 뒤입니다. 남은 초는 창에 한 줄로 나옵니다. [닫기]로 닫아도 Hi Coffer는 계속 실행됩니다. BitLocker로 잠긴 저장 매체는 Windows에서 잠금을 풀면 바로 읽습니다. 데이터 폴더가 그 저장 매체에 있으면 다시 읽히는 즉시 이어서 동작합니다.

**「꽂은 저장 매체가 보이지 않습니다」 창.** 「Windows가 꽂은 저장 매체를 찾지 못하고 있습니다」라는 머리글로 뜹니다. 드라이브 문자가 생기지 않는 경우(「USB 장치를 인식할 수 없음」 등)에 Hi Coffer를 켠 뒤 새로 꽂았을 때 나옵니다. [안내 상자: 실행할 것]은 「USB 포트·연결선을 확인해 주십시오」: 저장 매체를 뺐다가 잠시 후 다른 USB 포트에 PC로 직접 꽂기, 연결선이 따로 있으면 다른 연결선으로 꽂기, 외장 하드를 여러 대 꽂았다면 다른 외장 하드를 빼고 이것만 꽂기(USB 전원이 모자랄 수 있음), 그래도 보이지 않으면 다른 PC에 꽂아 보기입니다. 다른 PC에서도 보이지 않으면 저장 매체가 고장난 것이므로 제조사에 수리를 요청하십시오. 저장 매체가 나타나면 「저장 매체가 나타났습니다」로 바뀌고 20초 뒤 닫힙니다. 나타났지만 응답이 없으면 「저장 매체가 응답하지 않습니다」(빨간 표시)로 바뀌며 「읽을 수 없습니다」 창이 이어받습니다.

## 6. 실행할 것 / 실행하면 안 되는 것

[안내 상자: 실행할 것]
- 새 판을 설치하기 전에 Hi Coffer를 닫으십시오.
- 설치 파일과 프로그램은 두 번 눌러 일반 권한으로 실행하십시오.
- 데이터 폴더는 처음 실행 창의 기본값(사용자 폴더 아래 `HiCoffer`)을 쓰십시오.
- 금고 복구 QR코드파일은 USB 등 외부 저장 매체에 보관하십시오.
- 목록표를 만들거나 정리하는 동안 저장 매체를 꽂아 둔 채 기다리십시오. 멈추려면 [중지]를 누르십시오.
- 제안함의 미리보기(줄에 올려 보이는 「지금 위치」, 「실행 후 위치」, 「이유」)를 확인한 뒤 [선택 실행]을 누르십시오.
- 정리를 잘못했다면 이력·되돌리기에서 묶음 단위로 되돌리십시오.
- 일을 마치면 금고를 잠그십시오.
- 문제가 생기면 [지원 정보 저장]으로 파일을 만들어 문의하십시오(7장).

[안내 상자: 실행하면 안 되는 것]
- 설치 파일이나 프로그램을 관리자 권한으로 실행하지 마십시오(금고로 끌어다 놓기가 막힙니다).
- 데이터 폴더를 OneDrive 같은 클라우드 동기화 폴더에 두지 마십시오(목록표의 파일 이름·경로와 금고 파일이 클라우드로 올라갑니다).
- 데이터 폴더와 각 저장 매체 맨 위의 `00_관리` 폴더를 옮기거나 지우지 마십시오.
- 금고 비밀번호와 금고 복구 QR코드파일을 둘 다 잃지 마십시오. 둘 다 잃으면 금고를 열 수 없고, 운영자도 열 수 없습니다.
- 금고 복구 QR코드를 클라우드·메신저·SNS로 공유하지 마십시오.
- 「자동 실행」은 규칙을 충분히 확인하기 전에 켜지 마십시오. 켜면 확인 없이 옮깁니다.
- 제안함의 [선택 실행]은 미리보기를 확인하기 전에 누르지 마십시오.
- Windows가 저장 매체를 「포맷」하거나 「초기화」하라고 물으면 [취소]를 누르십시오.
- 저장 매체가 불안정하게 읽히는 동안 그 저장 매체로 파일을 옮기거나 복사하지 마십시오.
- 목록표를 만들거나 정리하는 동안 저장 매체를 빼지 마십시오.
- 금고 비밀번호·금고 복구 QR코드파일·개인 파일을 문의 메일에 첨부하지 마십시오.

## 7. 문제가 생겼을 때

### 7-1. 먼저 해 볼 것(위에서부터 차례로)

1. 프로그램이 열리지 않거나 이상하면 배포판 폴더의 최신 설치 파일을 다시 실행하십시오. 제거하지 않아도 프로그램 파일을 모두 새로 덮어써 복구합니다. 데이터 폴더·설정·금고는 그대로입니다. Hi Coffer가 응답 없이 남아 있으면 설치 파일이 대신 닫을지 묻습니다.
2. 그래도 이상하면 Windows 설정의 앱에서 「Hi Coffer」를 제거한 뒤 설치 파일을 다시 실행하십시오. 데이터 폴더·설정·금고는 남아 있어 그대로 이어 씁니다.
3. 바로가기를 눌렀는데 앞서 실행한 Hi Coffer가 응답하지 않으면 「Hi Coffer가 응답하지 않습니다」 창에서 [닫고 새로 시작]을 누르십시오.
4. 컴퓨터 다시 시작은 위 방법으로도 안 될 때만 하십시오.
5. 데이터 폴더를 찾지 못하면 2-5를 따르십시오.
6. 설정 파일이 손상되면 처음 실행 창이 다시 나옵니다. 같은 데이터 폴더를 고르면 기존 자료를 그대로 이어 씁니다.
7. 저장 매체를 뺐다가 다시 꽂으면 장치·매체 화면에 바로 다시 표시됩니다.

### 7-2. 지원 정보 저장

문의하기 전에 [정보] 화면의 [지원 정보 저장]을 누르십시오.

1. 왼쪽 메뉴에서 「정보」를 누르고 [지원 정보 저장]을 누릅니다.
2. 프로그램이 자체 시험을 돌립니다. 자체 시험은 사용자 자료를 건드리지 않고 임시 폴더에서만 여러 기능(내용 지문, 형식 구별, 보호 자산, 위협 판별, 이력 기록의 사슬, 암호화, 이동·되돌리기 등)을 독립적으로 시험하고, 결과를 이력 기록에 남깁니다.
3. 판, Hi Coffer ID, Windows 판, 화면 배율, 자체 시험 결과를 담은 파일 하나가 데이터 폴더 아래 `지원정보` 폴더에 저장됩니다. 파일 이름은 `HiCoffer_지원정보_(날짜_시각).txt` 꼴입니다. 상태 줄에 「지원 정보를 저장했습니다 · 자체 시험 n/n 통과」가 나옵니다.
4. 「지원 정보 저장」 창이 「지원 정보를 파일 하나로 저장했습니다. 문의할 때 이 파일을 보내 주십시오.」와 통과 건수를 알려 줍니다. [위치 열기]를 누르면 그 파일이 있는 폴더가 열리고, [그만두기]를 누르면 창만 닫습니다(파일은 이미 저장되어 있습니다).

이 파일에는 금고 비밀번호나 열쇠가 들어 있지 않습니다(담기는 항목은 위 3번과 같습니다).

### 7-3. 문의

- 접수: assist@hiven.ai.kr. 전자우편 주소는 이것 하나입니다. 앱 안에서 신고하는 기능은 베타2부터입니다.
- 응답 기한: 접수 확인 1영업일 안, 첫 답변 3영업일 안. 자료 손상, 금고를 열 수 없음 같은 긴급 건은 제목에 [긴급]을 붙이면 먼저 봅니다.

## 8. 낱말 풀이

| 낱말 | 뜻 |
|---|---|
| 저장 매체 | PC 안쪽 저장 장치와 USB 메모리·외장 하드·메모리 카드처럼 꽂아 쓰는 저장 장치를 모두 부르는 말 |
| 데이터 폴더 | Hi Coffer의 목록표·이벤트 원장·금고를 두는 폴더. 처음 실행 때 정함 |
| `00_관리` | 데이터 폴더와 각 저장 매체 맨 위에 만드는 관리 기록 폴더. 옮기거나 지우면 안 됨 |
| 목록표 | 저장 매체에 어떤 파일이 있는지 적은 표. 파일은 바꾸지 않음 |
| 대사(견주기) | 새 목록표를 앞 목록표와 맞대어 추가·변경·이동·누락을 찾는 일 |
| 자산 | Hi Coffer가 관리하는 파일 하나하나 |
| 자산 번호 | 자산마다 붙는 번호. 금고 코드가 앞부분에 들어감(HC-코드-연도-일련-검증) |
| 영역 | 파일을 나누는 열네 갈래(00~10, 97~99). 폴더 이름 앞에 번호를 붙여 씀 |
| 분류 체계(Hi DAM) | 영역으로 파일을 나누는 HIVEN의 기준. 저장 매체마다 4단계로 적용 |
| 프로필 | 분류 체계(Hi DAM)를 적용할 때 고르는 용도. 개인·기업·공공 |
| 입구 폴더 | 새 파일이 들어오는 폴더(다운로드 등). 검사와 감시의 대상 |
| 감시 | 정한 주기(분)마다 입구 폴더를 자동으로 검사하는 일 |
| 제안 | 어디에 둘지 알려 주는 것. 사용자가 실행해야 파일이 옮겨짐 |
| 실행 수준 | 제안을 어떻게 실행하는지. A0 알림만, A1 자동, A2 묶음 확인, A3 항목 확인 |
| 고정 규칙 | 보호·보안을 위한 규칙. 사용자가 수준을 바꿀 수 없음(보호 자산, 이상징후) |
| 작업 묶음 | 한 번에 실행한 일을 묶은 단위. 되돌리기도 이 단위 |
| 이력 / 이력 기록 / 이벤트 원장 | 프로그램이 한 일을 적은 기록. 바뀐 적이 있으면 알아내도록 적음. 「원장 무결성 확인」은 이 기록이 바뀌지 않았는지 확인하는 일 |
| 격리함 | 지우지 않고 옮겨 두는 자리. 영구 삭제는 사용자가 탐색기에서 직접 함 |
| 보호 자산 | 공동인증서·개인키 파일. 옮기지 않고 위치만 기록함 |
| 금고 | 고른 파일을 이 PC에서 암호화해 보관하는 곳 |
| 금고 복구 QR코드 / 금고 복구 QR코드파일 | 금고 비밀번호를 잊었을 때 금고를 여는 열쇠 / 그것을 저장한 파일(.png). 기기마다 1개. 「복구」는 이 열쇠에만 씀 |
| 원본 지문(SHA-256) | 파일 내용에서 계산한 짧은 값. 금고에 넣을 때와 같은지 비교해 바뀌었는지 확인함 |
| R0 | 영구 보존 등급(예: 01 신분·학위·자격). 「금고 후보 보기(R0 문서)」가 찾는 대상 |
| D0~D4 | 검색의 「등급」 고르기 값. 뜻은 아래 「확인 안 됨 표」 참고 |
| 자산 관리 상태 | 맨 위 표시등과 홈 카드. 불안(처음) · 혼재(한 번 이상 정리함) · 양호(베타1 이용 중) · 최적(베타1 이용 중 + 분류 체계(Hi DAM) 적용) |
