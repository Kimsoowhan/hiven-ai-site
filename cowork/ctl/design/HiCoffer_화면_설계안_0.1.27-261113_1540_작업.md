### 17-3. 자산 탐색 화면 (새 화면, 메뉴에서 장치·매체 다음)
파일 탐색기와 같은 틀로 「어디에 무엇이 있는지」를 본다. 목록표(이미 있는 자료)에서 읽으므로 분리된 저장 매체도 보인다.
- 왼쪽 나무(너비 240): 저장 매체 ▸ 영역(00~99) ▸ 범주 ▸ 폴더. 줄마다 펼침 ▸/▾, 아이콘, 이름, 오른쪽에 개수. 분리된 매체는 흐리게 + 「분리」 표지. 금고는 맨 아래 따로 한 줄.
- 위쪽 길 줄(높이 36): 「저장 매체 › 영역 › 범주 › 폴더」 각 마디를 누르면 그 자리로, 오른쪽에 이 자리 안에서 찾기.
- 오른쪽 목록(직선 표): 이름 · 종류 · 영역 · 등급 · 크기 · 고친 날 · 자산 번호. 머리를 눌러 정렬, 두 번 누르면 폴더는 들어가고 파일은 [폴더 열기].
- 아래 정보 줄(높이 32): 이 자리의 개수·용량, 고른 항목의 전체 경로 + [경로 복사] · [폴더 열기] · [금고에 넣기].
- 보기 바꿈: 「자리로 보기(저장 매체 기준)」 ↔ 「분류로 보기(영역 기준: 영역 ▸ 범주 ▸ 저장 매체)」. 같은 자산을 두 길로 본다.
- 배치(1080×608): 본문 y=150부터. 길 줄 808×36 → 8 → 2단(나무 240×330 · 사이 16 · 목록 552×330) → 8 → 정보 줄 808×32.
- 장치·매체·검색·제안함·이력의 줄에는 「자산 탐색에서 보기」 동작을 오른쪽 누름 메뉴에 둔다.
- 이로써 메뉴는 11개: 홈 · 장치·매체 · 자산 탐색 · 분류 체계(Hi DAM) · 제안함 · 자동 정리 규칙 · 금고 · 검색 · 이력·되돌리기 · 격리함 · 정보(항목 높이 40 × 11 = 440, 16-1 메뉴 높이 안).

### 17-4. 탐색기 구조를 기본으로, 본 창에 못 담으면 넓히거나 따로 띄운다 (이력 1216, 대표님 15:24)
- 기본 구조: 자산을 다루는 화면(장치·매체, 자산 탐색, 제안함, 금고, 검색, 이력·되돌리기, 격리함)은 모두 탐색기와 같은 뼈대를 쓴다 — 위 길 줄(지금 보는 자리) · 왼쪽 나무(접을 수 있음) · 오른쪽 목록 · 아래 정보 줄. 화면마다 나무의 뿌리만 다르다(제안함은 「옮기기 전 자리 ▸ 옮길 자리」, 금고는 「금고 ▸ 영역 ▸ 원본 폴더」, 이력은 「작업 묶음 ▸ 옮긴 항목」, 격리함은 「격리한 날 ▸ 원래 자리」).
- 본 창(1080×608)에 다 못 담을 때의 차례:
  ① 창 안에서 넓히기: 나무 접기 단추(◀)로 목록을 808 전체 너비로, 나무와 목록 사이 경계를 끌어 너비 조절(나무 160~400), 창 최대화·끌어 늘리기(늘어난 만큼 목록과 나무가 받음), 마지막 너비를 기억.
  ② 따로 뜨는 「자산 탐색 창」: 크기 960×600(끌어 늘림·최대화 가능, 본 창과 나란히 둘 수 있음), 틀은 17-3과 같되 나무 280·목록·오른쪽 「자세히」 칸 240(고른 항목의 전체 경로·영역·등급·크기·날짜·자산 번호·작업 이력). 본 창을 막지 않는다(여러 개 띄울 수 있음).
- 따로 뜨는 창을 여는 자리: 모든 자산 화면의 [탐색 창으로 보기] 단추와 줄의 오른쪽 누름 메뉴 「자산 탐색에서 보기」, 그리고 결과 확인 — 제안 실행·정리 계획 실행·금고에 넣기·되돌리기·검색이 끝나면 끝 알림에 [결과를 탐색 창으로 보기]를 두어, 옮긴 항목이 지금 어디에 있는지(새 자리에 강조 표시)와 옮기기 전 자리(흐린 줄 + 「여기서 옮김」)를 한 창에서 본다.
- 실행 전 미리보기도 같은 창: [선택 실행] 전에 「옮기기 전 ↔ 옮긴 뒤」를 두 나무로 나란히 보이고 [옮기기]·[그만두기].
- 사용자 중심 확인: 탐색 창에서는 보기·찾기·폴더 열기·경로 복사·금고에 넣기·되돌리기만 한다. 설정·규칙 같은 관리 기능은 두지 않는다.

## 18. 진행 상태 표시 — 지금 무엇을 하고 얼마나 됐는지 눈으로 보인다 (이력 1217, 대표님 15:26)
사-08(정적)의 예외: 작업이 도는 동안의 「도는 원」과 진행 막대, 단계 표시의 움직임은 허용한다(일이 없을 때는 아무것도 움직이지 않는다).
### 18-1. 세 자리에서 보인다
| 자리 | 언제 | 무엇을 |
|---|---|---|
| 진행 띠(내용 상자 맨 위, 높이 48) | 작업이 도는 동안 어느 화면에서나 | 도는 원 20px · 작업 이름 · 지금 단계 글 · 진행 막대 · 「63% · 1,204 / 1,912건」 · 남은 시간 어림 · [자세히] · [중지] |
| 진행 창(너비 560, [자세히]를 누르거나 파일을 옮기는 작업은 저절로) | 작업이 도는 동안, 끝나면 결과로 바뀜 | 18-2 |
| 상태 줄(맨 아래)·메뉴 | 늘 | 상태 줄 왼쪽에 도는 원 + 한 줄 요약, 작업이 도는 화면의 메뉴 항목 오른쪽에 작은 도는 원 |
### 18-2. 진행 창의 구성 (위에서 아래)
1. 머리: 도는 원 32px + 작업 이름(16px 700) + 「진행 중」 표지. 끝나면 원이 ✓(초록)·!(주황)·✕(빨강)으로 바뀌고 「완료」「일부 완료」「멈춤」.
2. 단계 목록(세로, 줄 32): 단계마다 ○ 대기 → 도는 원 진행 중 → ✓ 끝 + 그 단계의 건수. 지금 단계는 굵게.
3. 진행 막대(높이 8) + 「63%」(24px 800) + 「1,204 / 1,912건 · 3.2GB / 5.1GB · 남은 시간 약 2분」.
4. 지금 처리하는 항목 한 줄: 「옮기는 중: 사진\2024\IMG_0123.jpg → 06_개인·가족\06.01_사진·영상」(길면 가운데 줄임).
5. 과정 기록(직선 표, 최근 것이 위, 6줄 보이고 스크롤): 시각 · 한 일(옮김·건너뜀·격리함으로·금고에 넣음·목록표에 적음) · 항목 · 결과. 한 건 끝날 때마다 한 줄씩 올라온다.
6. 갈래별 세는 칸(한 줄): 「옮김 812 · 정리 폴더 만듦 14 · 중복 격리 96 · 건너뜀 3 · 실패 0」 — 숫자가 올라가는 것이 보인다.
7. 단추: 도는 동안 [중지](지금 항목까지 마치고 멈춤) · [창 닫고 계속](진행 띠로 줄어듦). 끝나면 [결과를 탐색 창으로 보기](17-4) · [되돌리기] · [닫기].
### 18-3. 작업 갈래별 단계 글 (화면에 그대로 쓴다)
| 작업 | 단계 |
|---|---|
| 목록표 만들기·대사 | ① 저장 매체 읽는 중 → ② 파일 세는 중 → ③ 앞 목록표와 견주는 중(추가·변경·이동·누락) → ④ 자산 번호 붙이는 중 → ⑤ 목록표 저장 중 → 끝 「목록표를 만들었습니다: 자산 n개, 추가 a · 변경 b · 이동 c · 누락 d」 |
| 분류 체계(Hi DAM) 적용·연동 | ① 분류 체계(Hi DAM) 불러오는 중 → ② 이 저장 매체의 영역과 짝짓는 중 → ③ 영역 폴더 만드는 중 → ④ 코드표 저장 중 → 끝 「분류 체계(Hi DAM)를 적용했습니다: 영역 n개」 |
| 정리 계획·입구 폴더 검사 | ① 폴더 살피는 중 → ② 분류 체계(Hi DAM) 규칙과 견주는 중 → ③ 중복 파일 찾는 중 → ④ 제안 만드는 중 → 끝 「제안 n건을 만들었습니다(옮기기 a · 중복 b · 분류 필요 c)」 |
| 선택 실행·자동 정리 | ① 옮기기 전 자리 기록 중(되돌리기용) → ② 파일 옮기는 중 → ③ 중복 파일을 격리함에 넣는 중 → ④ 목록표·이력에 적는 중 → ⑤ 옮긴 결과 확인 중 → 끝 「정리를 끝냈습니다: 옮김 a · 중복 격리 b · 건너뜀 c. 모두 되돌릴 수 있습니다」 |
| 되돌리기 | ① 작업 묶음 읽는 중 → ② 원래 자리로 옮기는 중 → ③ 빈 폴더 정리 중 → ④ 목록표·이력에 적는 중 → 끝 「되돌렸습니다: n건」 |
| 금고 만들기 | ① 금고 자리 만드는 중 → ② 비밀번호로 열쇠 만드는 중 → ③ 금고 복구 QR코드파일 만드는 중 → ④ 금고 잠금 확인 중 → 끝 「금고를 만들었습니다. 금고 복구 QR코드파일을 외부 저장 매체에 보관하십시오」 |
| 금고에 넣기 | ① 원본 지문 뜨는 중 → ② 암호화하는 중 → ③ 금고에 넣는 중 → ④ 넣은 것을 다시 풀어 원본과 같은지 확인 중 → ⑤ 금고 원장에 적는 중 → 끝 「금고 처리를 끝냈습니다: n개를 금고에 넣었고 원본과 같음을 확인했습니다」 |
| 금고 원본 확인·열람·해지 | 같은 틀로 단계와 끝 글(「원본과 같습니다 n개 · 다름 m개」 등) |
| 검색·AntiAD 검사 | ① 목록표 읽는 중 → ② 찾는 중/검사 중 → 끝 「n개를 찾았습니다」 |
- 중복 파일은 영구 삭제하지 않고 격리함에 넣는다(되돌릴 수 있음). 화면 글은 「격리함에 넣는 중」으로 쓰고 풍선 도움말에 「Windows 휴지통처럼 다시 꺼낼 수 있는 자리」라고 풀이한다.
- 퍼센트는 건수 기준(크기가 큰 작업은 용량 기준)으로 실제 처리한 수에서 계산한다. 셀 수 없는 단계(읽는 중)는 막대가 좌우로 흐르는 꼴로 보이고 퍼센트를 지어내지 않는다.
- 0.5초 안에 끝나는 일은 진행 창을 띄우지 않고 상태 줄 한 줄만. 10초 넘게 걸리면 남은 시간 어림을 보인다.
- 감시(자동 정리)가 켜져 있으면 맨 위 표지 「감시 켜짐」 옆에 마지막 검사 시각과, 검사 중에는 도는 원.
### 18-4. 끝 알림
진행 창이 결과로 바뀌고(닫지 않음), 상태 줄에 끝 글 한 줄, 본 창이 뒤에 있으면 작업 표시줄 단추가 한 번 반짝인다. 끝 글은 18-3의 「끝」 문장을 그대로 쓴다. 실패·건너뜀이 있으면 까닭과 할 일을 과정 기록 위에 따로 묶어 보인다.

## 19. 검사용 보기판 — 대표님이 화면으로 보시기만 하면 되게 (이력 1218, 대표님 15:28)
