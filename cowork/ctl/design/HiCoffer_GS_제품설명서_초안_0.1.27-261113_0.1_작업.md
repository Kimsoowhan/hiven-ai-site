## 1. 제품 소개

### 1.1 제품 개요 및 용도 (기준 5·8·17번)

Hi Coffer AI Agent(이하 「제품」)는 사용자가 쓰는 Windows PC와 거기에 꽂는 저장 매체(USB 메모리·외장 디스크 등)에 흩어진 파일을, 분류 체계(Hi DAM)의 기준 한 벌에 따라 목록으로 만들어 보고, 찾고, 정리하고, 중요한 파일을 암호로 잠가 보관하기 위해 사용됩니다.

본 제품으로 개인 사용자는 다음을 할 수 있습니다.
- 목록표 만들기·대사: 저장 매체마다 파일 목록표를 만들고, 앞 목록표와 견주어 추가·변경·이동·누락된 파일을 확인합니다. 파일을 옮기지 않습니다.
- 정리 제안과 선택 실행: 새 파일이 들어오는 폴더를 살펴 어디에 둘지 제안하고, 사용자가 확인해 [선택 실행]을 누른 것만 옮깁니다. 옮긴 것은 되돌릴 수 있습니다.
- 금고: 고른 파일을 이 PC에서 암호화해 보관합니다. 원본은 제자리에 둡니다.
- 찾기와 되돌리기: 모든 목록표에서 파일을 찾고, 옮긴 것을 원위치로 되돌립니다. 영구 삭제는 하지 않고 격리함에 둡니다.

본 제품 사용에는 파일·폴더·USB 저장 매체를 다루고 Windows 설정의 앱에서 프로그램을 설치·제거할 수 있는 정도의 지식이 필요합니다.
(근거: 앞서 쓴 작업본 2절·3절, 사용 설명서 1장. 사전 지식의 범위는 사용자 시험 전에는 확인 안 됨.)

## 3. 제품 설치 (기준 26번)

본 제품은 사용자가 설치 파일 HiCoffer_Setup_0.1.27.exe를 두 번 눌러 직접 설치합니다(관리자 권한 없이 현재 사용자 계정에만). 화면 순서는 환영 → 설치 전 고지와 이용 조건 → 설치 폴더 → 설치 진행 → 마침이고, 처음 실행하면 「Hi Coffer 시작하기」 창에서 데이터 폴더와 금고 코드를 정합니다. 설치 폴더의 처음 값은 `%LOCALAPPDATA%\Programs\HiCoffer`입니다. 설치 화면 전체의 캡처 목록은 `HiCoffer_설치_화면_캡처_목록-261113_0.1_작업.tsv`(IS-01~IS-32)이고, 이 절에 그 캡처를 차례대로 넣어야 합니다(없음).

같은 설치 파일을 다시 실행하면 프로그램 파일을 새로 덮어써 복구하고, 새 판은 덮어 올립니다. 이미 더 새로운 판이 있으면 이전 판으로 되돌릴지 묻습니다. 어느 경우든 데이터 폴더·설정·금고는 그대로 둡니다. 제거는 Windows 설정의 앱에서 「Hi Coffer」를 제거하며 데이터 폴더와 각 매체의 `00_관리`, 금고는 지우지 않습니다.

설치 지원: 설치 안내는 README.txt와 사용자취급설명서에 있고, 방문 설치는 하지 않습니다(확인 안 됨: 제공하는지 정해야 함).
