## 2. 용도와 대상

**용도.** 사용자가 쓰는 PC와 저장 매체(USB·외장 디스크 등)에 흩어진 파일을 한곳의 기준(분류 체계 Hi DAM)으로 정리하고 기록하며, 중요한 파일은 이 PC에서 암호화해 보관하는 Windows 응용 프로그램입니다. 모든 처리는 사용자의 PC 안에서 이루어집니다.

**하는 일.**
- 저장 매체마다 파일 목록표를 만들고 앞 목록표와 견주어 추가·변경·이동·누락을 알려 줍니다(「대사」).
- 분류 체계(Hi DAM)의 영역 14개에 맞춰 폴더를 만들고, 파일을 옮기자는 제안을 만듭니다. 사용자가 미리보기를 확인하고 [선택 실행]을 눌러야만 옮깁니다.
- 옮긴 것은 이력에 남기고 되돌릴 수 있습니다. 영구 삭제는 하지 않고 격리함으로 옮깁니다.
- 중요한 파일을 금고(비밀번호와 금고 복구 QR코드로 여는 암호화 보관소)에 넣습니다.
- 목록표를 대상으로 파일을 검색합니다.

**대상 사용자.** 디지털 파일을 직접 정리하려는 개인 사용자(컴퓨터에 익숙하지 않은 분 포함). 기업·기관 사용자를 위한 기능(여러 사람이 함께 쓰기, 중앙 관리)은 이 판에 없습니다(확인: 소스에 해당 기능 없음).

**분류 체계(Hi DAM v0.1).** HIVEN이 정한 디지털 자산 분류 기준입니다. 영역 14개는 다음과 같습니다(`src/Core/Standard.cs`).

| 번호 | 영역 이름 | 번호 | 영역 이름 |
|---|---|---|---|
| 00 | 관리 | 06 | 개인·가족 |
| 01 | 신분·학위·자격 | 07 | 행정·세무·법무 |
| 02 | 경력·구직 | 08 | 자료실 |
| 03 | 근무·프로젝트 | 09 | 설치·소프트웨어 |
| 04 | 사업·창업 | 10 | 관계·네트워크 |
| 05 | 학습·연구 | 97 | 원천보관 |
| | | 98 | 임시 |
| | | 99 | 기타 |

영역마다 하위 범주(예: 04.02 Hi Coffer), 자산 등급(D0~D4)과 보존 등급(R0~R4)이 코드에 정해져 있습니다. 이 분류 체계의 기준 문서(영역·범주·판별 규칙)를 한 문서로 동결하는 일은 아직 하지 않았습니다(계획서 G1, 확인 안 됨).

**적용한 표준·권고안.** 이 제품 자체가 따르는 외부 표준은 확인 안 됨 — 찾아본 곳: 소스 머리글, README, 사전 고지, 정의서. 금고 암호 방식(AES-256, PBKDF2-SHA256, HMAC-SHA256)과 지문 방식(SHA-256)의 이름은 소스에 있습니다(5-6절). GS 인증 평가 기준은 KS ISO/IEC 25023·25051이며 이 제품의 인증은 아직 받지 않았습니다.

**수행하지 않는 것.** 법적 원본 증명(공인전자문서센터 수준)을 하지 않습니다. 금고의 「원본 확인」은 넣을 때 기록한 지문(SHA-256)과 같은지 보는 기능입니다(`notice.txt` 6항).

## 5. 품질 특성별 주장과 근거

## 7. 설치와 제거 요약

**설치.**
1. 설치 파일 `HiCoffer_Setup_0.1.27.exe`를 두 번 눌러 실행합니다(관리자 권한으로 실행하지 않습니다).
2. Hi Coffer가 실행 중이면 설치 파일이 닫을지 묻습니다. 이 PC에 .NET Framework 4.8 이상이 없으면 설치가 멈춥니다.
3. 설치 전 고지를 읽고 「위 내용을 읽고 확인했습니다」를 체크한 뒤 설치 폴더를 정합니다. 처음 값은 「%LOCALAPPDATA%\Programs\HiCoffer」이며 이전에 설치한 폴더가 있으면 그 폴더를 이어 씁니다.
4. 설치가 끝나면 바탕화면과 시작 메뉴에 「Hi Coffer」 바로가기가 생깁니다. 처음 실행할 때 사전 고지를 확인하고 데이터 폴더(기본 사용자 폴더\HiCoffer)와 금고 코드(4자)를 정하고 시작합니다.

**같은 판을 다시 실행하면** 프로그램 파일을 모두 새로 덮어써 복구합니다(데이터 폴더·설정·금고는 그대로). 새 판은 이 방식으로 덮어 올리고, 이미 더 새로운 판이 있으면 이전 판으로 되돌릴지 묻습니다.

**제거.** Windows 설정 > 앱에서 「Hi Coffer」를 제거합니다. 데이터 폴더·각 매체의 `00_관리` 폴더·금고는 지우지 않습니다. 다 지우려면 사용자가 직접 지워야 합니다.

근거: `installer/HiCoffer.nsi`, `installer/README.txt`.
