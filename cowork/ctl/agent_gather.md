# agent_gather.tsv 칸 설명 (에이전트 수집 대장 · 대표님 이력 1061)

소넷 5.5가 부른 모든 에이전트(Fable·오파스·소넷 보조)가 모은 상황과 산출을 데이터 파일로 먼저 저장하는 대장입니다. 에이전트 보고를 받으면 그 즉시 한 줄을 더하고, 진행 중 줄은 보고가 오면 같은 줄을 채웁니다(줄을 지우지 않음).
- 번호: G-숫자, 이어서 늘림.
- 수집 시각: 산출 파일 수정 시각(보고를 받기 전 줄은 비움).
- 에이전트·일감: 누가 무엇을 맡았는지.
- 수집한 상황(요지): 보고의 사실만. 보고에서 확인 안 됨이면 「확인 안 됨」.
- 산출 파일·sha256 앞 16자: 로컬에서 직접 계산한 값. 보고서의 해시를 옮겨 적지 않음.
- 반영 위치: 이력 번호·판정요청 번호·지시문 일감 번호.
- 상태: PC 재수신 대조 결과까지 적음. 실측이 아닌 값(시뮬레이션)은 구분 딱지를 붙임.
