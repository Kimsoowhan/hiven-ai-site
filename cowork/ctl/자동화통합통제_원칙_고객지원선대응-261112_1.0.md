# 자동화 통합 통제 원칙 · 고객 지원 선대응 (대표님 2026-11-12 16:19, 이력 907)
HIVEN 자동화 통합 통제 체계와 시스템의 기본 원칙이다. 모든 HIVEN 통합사업(HiDAM·HiCoffer·HiServe·HiSilver·HiASI·HiICT·HiTrade)의 데이터·파일·문서에 같은 내용으로 적용한다.

## 1. 원칙
1. 선대응 후 응대: 고객 지원은 도착 즉시 감지하고, 위험부터 막은 뒤(대응) 답한다(응대).
2. 자동 수집: Gmail에 연동된 assist@hiven.ai.kr(고객 지원)과 contact@hiven.co.kr(투자·협력·후원)으로 들어오는 메일을 자동으로 읽어 들인다.
3. 자동 감지: 감지 규칙(cowork/ctl/cs_rules.tsv R-01~R-07)에 맞는 단어·요건이 있으면, 받는 주소가 다르거나 연결이 끊긴 경우에도 고객 지원 건으로 잡는다.
   - 대상: 도움 요청, 오류, 불편·클레임, 환불·결제, 보안, 데이터 손실, 제휴
4. 즉시 얼럿: 감지 즉시 통합관제 대시보드에 얼럿을 띄운다.
   - 상단 띠: 「고객 지원 · 선대응 N건」
   - SC-17 얼럿
5. LED 표시: 다른 화면과 같은 LED 체계를 쓴다.
   - 선대응 필요: 빨강 깜빡임
   - 대응·응대 중: 주황
   - 종결: 초록
6. 연동: SC-17은 SC-00~SC-16 전체와 연결된다(cs_links.tsv). 회신은 대표님 결재(SC-00) 뒤에만 보낸다.
7. 역할: 기술은 Opus 5.5, 서비스는 Sonnet 5.5, 결재는 대표님, 최종 판정은 Fable 5.2가 맡는다.
8. 비밀 보호: 로그인 코드·비밀번호 같은 비밀 값은 저장하지 않는다(분류기가 6자리 숫자를 가림).

## 2. 구현 (hiven.ai.kr, views9.js?v=20261112v1)
- 감지 규칙: cowork/ctl/cs_rules.tsv
- 분류기: tools/gen_cs.py
  - 입력: cs_inbox.tsv(수집분)
  - 출력: cs_tickets.tsv에 새 건 추가(긴급도·담당·선대응·연관 화면)
- 화면:
  - SC-17 얼럿·대장(선대응 필요 건은 빨강 깜빡임)
  - 상단 띠 「고객 지원」 버튼(누르면 SC-17, 휴대폰에서는 새 건이 오면 띠를 다시 표시)

## 3. 자동 수집의 실제 범위 (사실)
- Gmail 읽기는 작업 모델(Opus)이 Gmail 연결로 수행한다.
- 예약 작업이 금지되어 있으므로, 모델이 일하는 동안 매 작업 차례마다 수집 → 분류 → 화면 반영을 한다.
- 모델이 일하지 않는 시간에는 도착 즉시 얼럿이 아니다. 다음 작업 차례에 바로 잡힌다.
