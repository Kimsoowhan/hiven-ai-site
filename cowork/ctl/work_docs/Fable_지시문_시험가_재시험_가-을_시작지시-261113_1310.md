## 2. Fable 판정

1. 가-갑 회차의 종료는 안내 창이 닫히고 5초 뒤 **주 화면이 닫힌 것**이다. 누가 닫았는지는 0.1.25 기록으로는 가릴 수 없다. 0.1.26은 닫힘 경로(창의 닫기 단추·바깥 요청·Windows·작업 관리자)를 기록한다.
2. 0.1.26 설치 파일은 공개 저장소에 올리지 않는다. 시험 PC로 직접 올린다.
3. 바깥 닫기 요청에 확인 창을 넣는 일은 이번에 하지 않는다(베타 2 범위 판정 때 다시 본다).
4. **재시험 동안 어떤 모델도 시험 PC의 화면을 조작하지 않는다.** 화면을 건드리는 것은 시작과 끝 두 번뿐이고 매번 이력에 남긴다. 그 사이에는 파일 읽기만 한다.
5. 재시험은 짧은 회차(Short)를 먼저 통과한 뒤에만 24시간 회차(Full)를 시작한다.
